# Thirsty app


This is an app to remind myself to water my plants.
## Installation
```
npm instal
npm run dev
```

Docker
```
docker build . [image]
docker run -d --rm -p 5173:5173 --name [container] [image] 
```

## Technologies

- Vite
- Vitest
- Typescript
- React
